# Egyptian Currency Classifier

This project aims to train a machine learning model to recognize and classify the value of Egyptian paper currency from images. 

## Dataset
The model is trained using the **Egyptian New Currency 2023** dataset obtained from Kaggle.
* **Source:** [Kaggle - Egyptian New Currency 2023](https://www.kaggle.com/datasets/belalsafy/egyptian-new-currency-2023)

## Goal
To develop an efficient classification model that can accurately distinguish between different denominations based on visual features like color and patterns.
